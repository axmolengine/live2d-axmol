# Live2D Runtime for Axmol v3

---

## 📦 Usage

1. Remove all files under `axmol/extensions/live2d`.
2. Switch to specified branch, for example: `5.x`.
3. All files in this repo (exclude .git) into `axmol/extensions/live2d/`.

---

## 🎯 Supported Live2D Versions

- 5.x (5.5)
- 4.x (4.4)
